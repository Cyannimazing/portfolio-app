# Project asset provenance

The current 20-project collection uses live previews with actual screenshot fallbacks listed in `lib/project-previews.ts`. Those assets remain in `public/projects/previews` and the three saved original fallback screenshots remain in `public/projects`.

The three separate legacy case studies (FaithSeeker, AidPoint and F.A Babila Architects) retain their optimized covers and any linked gallery screenshots. [generated-covers.json](./generated-covers.json) retains their exact generation prompts, and [image-map.json](./image-map.json) records only optimized images still used by those pages. Historical input paths may refer to original captures removed at the user's request.

Unused source images, presentation drafts, mockups, videos, temporary scripts and obsolete manifests were removed during the October 9 cleanup. Published service/contribution evidence and the saved profile Markdown remain available in the repository.
